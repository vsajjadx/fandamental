# Fandamental

دستیار تحلیل بازار (وب‌اپ بدون بک‌اند): **فاندامنتال (اخبار با AI) + تکنیکال (۲۸ اندیکاتور) + پرایس‌اکشن** → جهت احتمالی، ناحیه‌ی ورود، حد ضرر، سه تارگت و «امتیاز هم‌سویی».

## اجرا

```bash
python3 -m http.server 8080     # داخل پوشه‌ی پروژه
# سپس باز کنید: http://localhost:8080
```

یا مستقیم `index.html` را در مرورگر باز کنید. اینترنت لازم است (چارت‌های TradingView، قیمت‌ها، API).

## تنظیمات (⚙ بالای صفحه)

| مورد | کاربرد |
|---|---|
| سرویس AI + کلید | **Google Gemini (رایگان، پیش‌فرض)**: کلید از https://aistudio.google.com/apikey بدون کارت بانکی. **OpenRouter**: مدل‌های رایگان از https://openrouter.ai/keys. **Anthropic Claude**: پولی ولی با جستجوی زنده‌ی وب. بدون کلید هم اپ کامل کار می‌کند؛ فقط لایه‌ی «تحلیل خبری با AI» و «رتبه‌بندی با AI» غیرفعال می‌ماند |
| کلید Twelve Data (اختیاری، رایگان) | فقط برای **تایم‌فریم‌های دقیقه‌ای** (۵m/۱۵m/۱h) روی فارکس، فلزات، نفت و شاخص‌ها. بدون این کلید، تایم‌فریم خودکار روی 1D تنظیم می‌شود |

### منابع داده (همه رایگان، بدون کلید، مستقیم از مرورگر)

| دارایی | منبع اصلی | جایگزین‌ها |
|---|---|---|
| کریپتو، طلا | Binance + **Nobitex + Wallex** (هر سه هم‌زمان؛ اولین پاسخ معتبر برنده است) | Yahoo |
| فارکس | Frankfurter (روزانه، بیش از یک سال) | Yahoo |
| نقره، پلاتین | CoinGecko (روزانه) | Yahoo |
| نفت WTI، شاخص‌ها (DXY/S&P/Nasdaq/Dow) | Yahoo Finance | Twelve Data با کلید |
| قیمت لحظه‌ای طلا/نقره/پلاتین | gold-api.com | goldprice.dev |
| بورس تهران | TSETMC (cdn.tsetmc.com) + سه رله‌ی رایگان CORS | جستجوی زنده در نوار کنار صفحه |
| اخبار | GDELT DOC 2.0 | Yahoo Finance News |
| تقویم اقتصادی | ForexFactory (nfs.faireconomy.media) | حافظه‌ی موقت مرورگر |

هر منبعی که پاسخ ندهد، زنجیره به منبع بعدی می‌رود؛ اگر همه بسته باشند، پیام خطای واقعی روی صفحه نمایش داده می‌شود (هیچ صفحه‌ای در حالت «در حال دریافت…» نمی‌ماند).

سرویس‌های رایگان جستجوی وب ندارند؛ به‌جایش اپ تیترهای ۳ روز اخیر را از GDELT (و برای کریپتو از CryptoCompare) می‌گیرد و به مدل می‌دهد تا فقط بر پایه‌ی همان‌ها تحلیل کند. عمق این تحلیل کمتر از حالت پولی است و سهمیه‌ی رایگان محدود است (خطای 429 یعنی چند دقیقه صبر کن). اسم مدل‌ها در تنظیمات قابل ویرایش است.

کلیدها فقط در `localStorage` مرورگر خودتان ذخیره می‌شوند. **اپ را با کلید شخصی روی سایت عمومی (مثلاً GitHub Pages) منتشر نکنید.**

## کار در ایران (بدون VPN)

- **هیچ CDN بیرونی لازم نیست.** کتابخانه‌ی چارت و فونت‌ها (وزیرمتن، JetBrains Mono) داخل خود ریپو هستند (`vendor/`)؛ صفحه حتی اگر unpkg یا Google Fonts فیلتر باشند بالا می‌آید. بعد از اولین بازدید، سرویس‌ورکر (`sw.js`) خود اپ را کش می‌کند و دفعه‌ی بعد فوری و حتی آفلاین باز می‌شود (داده‌ها همیشه زنده‌اند و کش نمی‌شوند).
- **منابع داده هم‌زمان (hedged) صدا زده می‌شوند، نه پشت‌سر‌هم.** پشت فیلترینگ، سایت مسدود معمولاً خطا نمی‌دهد و فقط منتظر می‌گذارد. اپ منبع اول را فوراً می‌زند، و اگر خطا داد یا بعد از ~۱ ثانیه جواب نیامد منبع بعدی را هم‌زمان شروع می‌کند؛ اولین جواب معتبر می‌برد. برای کریپتو، Nobitex و Wallex (هاست‌شده در ایران) کنار Binance هستند.
- **بورس تهران** مستقیم از TSETMC (از IP ایران باز می‌شود).
- **هوش مصنوعی:** Gemini و Claude برای IP ایران توسط خود سازنده‌شان مسدودند. در ⚙ تنظیمات یکی از این‌ها را انتخاب کنید: **OpenRouter**، یا **«سازگار با OpenAI»** با DeepSeek (`https://api.deepseek.com`، مدل `deepseek-chat`) یا درگاه‌های ایرانی مثل AvalAI (`https://api.avalai.ir/v1`) و GapGPT (`https://api.gapgpt.app/v1`). بدون هیچ‌کدام هم رتبه‌بندی محلی و تحلیل تکنیکال کار می‌کند.
- **رله‌ی شخصی (اختیاری):** اگر منبعی در شبکه‌ی شما بسته است (مثلاً Yahoo)، یک رله‌ی CORS شخصی (مثلاً یک Worker یا سرور کوچک) در تنظیمات بگذارید؛ قالب `https://relay.example.com/?url=` (آدرس هدف به‌صورت encode‌شده اضافه می‌شود) یا `https://relay.example.com/p/{url}`.
- **ویجت‌های TradingView** (نوار قیمت، چارت زنده) از سرور TradingView می‌آیند و ممکن است روی بعضی اینترنت‌ها باز نشوند؛ در آن صورت پیام راهنما نشان داده می‌شود و «چارت تحلیلی» خود اپ (با ورود/حد ضرر/تارگت) بدون آن کار می‌کند.

> هیچ برنامه‌ای نمی‌تواند وجود اینترنت یا باز بودن یک سایت در شبکه‌ی شما را تضمین کند؛ فهرست بالا فقط وابستگی‌های اپ را به حداقل رسانده و برای هر کدام راه جایگزین گذاشته است.

## بخش‌ها

- **چارت تحلیلی**: کندل + EMA/بولینگر/VWAP/Supertrend، سطوح حمایت/مقاومت، خطوط Entry/SL/TP، RSI و MACD
- **چارت TradingView**: چارت کامل TradingView برای همه‌ی ارزها، کریپتو، طلا، نقره، شاخص‌ها (تمام اندیکاتورهای خود TradingView از داخل همین چارت قابل افزودن است) + نوار قیمت و «نمای کلی بازارها»
- **سیگنال**: جهت، امتیاز هم‌سویی، نقاط ورود/خروج، دلایل و هشدارها، ماشین‌حساب حجم
- **اندیکاتورها**: جدول همه‌ی اندیکاتورها و پرایس‌اکشن با نظر هرکدام
- **فاندامنتال**: تحلیل خبری AI (اخبار ۷۲ ساعت اخیر + رویدادهای پیش‌رو) + اخبار و تقویم اقتصادی TradingView
- **هم‌فکری AI**: گفتگو درباره‌ی تحلیل، ارسال اسکرین‌شات چارت، بررسی اشتباهات ژورنال
- **بک‌تست**: اجرای walk-forward همین موتور روی کندل‌های واقعی برای دیدن دقت واقعی
- **ژورنال**: ثبت معاملات، نرخ برد، میانگین R، خروجی JSON
- **MT5**: ارسال همین سیگنال‌ها به متاتریدر ۵ (فقط نمایش / اجرا پس از تأیید / اجرای خودکار) با کنترل ریسک. **بدون سرور**: وقتی وب‌اپ (Chrome/Edge) و متاتریدر روی یک کامپیوترند، از طریق پوشه‌ی مشترک متاتریدر وصل می‌شوند؛ فقط اکسپرت `mt5/FandamentalBridge.mq5` لازم است. حالت پیشرفته با سرور (`server/`) برای وقتی که متاتریدر روی کامپیوتر دیگری است. راهنمای کامل: [docs/MT5.md](docs/MT5.md)

## نکات مهم و صادقانه

- **«امتیاز هم‌سویی» احتمال سود نیست.** نشان می‌دهد چند درصد از سیگنال‌های مستقل هم‌جهت‌اند. هیچ سیستمی دقت ۷۰٪ تضمین نمی‌کند. برای دانستن دقت واقعی از تب **بک‌تست** و **ژورنال** استفاده کنید و فقط وقتی «نرخ برد» از «سر‌به‌سر» بالاتر بود (با حداقل ~۳۰ معامله) به سیستم تکیه کنید.
- روی داده‌ی تصادفی (random walk) موتور هیچ لبه‌ای نشان نمی‌دهد (نرخ برد ≈ سر‌به‌سر)، که رفتار درست و بدون نشت اطلاعات آینده است.
- هیچ ابزاری «تک‌تک اخبار جهان» را نمی‌خواند؛ AI مهم‌ترین اخبار مرتبط را جستجو می‌کند و ممکن است اشتباه کند.
- اندیکاتورهای اختصاصی TradingView قابل کپی نیستند؛ ۲۸ اندیکاتور استاندارد اینجا پیاده شده و بقیه را می‌توانید در چارت TradingView اضافه کنید.
- منبع داده‌ی فارکس بدون حجم است؛ اندیکاتورهای حجمی در آن حالت خودکار کنار گذاشته می‌شوند.
- این ابزار مشاوره‌ی مالی نیست.

## ساختار و تست

```
index.html  css/style.css
js/indicators.js   اندیکاتورها (توابع خالص)
js/priceaction.js  سوینگ، ساختار بازار، سطوح، الگوهای کندلی، فیبو، پیوت
js/signal.js       امتیازدهی، هم‌سویی، پلن معامله
js/data.js         لیست نمادها + دریافت کندل (Binance / Twelve Data / CSV)
js/backtest.js     بک‌تست walk-forward
js/ai.js           سرویس‌های AI (Gemini / OpenRouter / Anthropic)، تیترهای GDELT، چت، تصویر
js/mt5.js          تب MT5: ارسال سیگنال به سرور پل، مدیریت اتصال‌ها و گزارش سفارش‌ها
js/app.js          رابط کاربری
server/            سرور پل MT5 (Python: Starlette + Pydantic + SQLite)
mt5/FandamentalBridge.mq5   اکسپرت متاتریدر ۵
docs/MT5.md        راهنمای راه‌اندازی، امنیت و تست اتصال MT5
tests/*.test.js
```

```bash
node tests/engine.test.js && node tests/mt5.test.js && node tests/mt5_direct.test.js
cd server && python3 -m unittest discover -s tests && python3 tests/e2e_ea_sim.py
```
